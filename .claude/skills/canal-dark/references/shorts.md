# Shorts

Short é adaptação editorial, **não** crop do long-form.

Estrutura:

```
HOOK → CONTEXT → ESCALATION → PAYOFF → CTA
```

`POST /api/editorial/shorts/adapt` mapeia o contrato CWM (`hook/setup/problem/insight/value/proof/cta`) para esta estrutura.

Produção: plataforma `YOUTUBE_SHORT` (~40s, ~5 cenas após Visual Director). `PlatformProductionProfiles` manda resolução 1080×1920.

Não tratar o Short como “o mesmo vídeo cortado”. Reescrever frases para retenção vertical; manter character lock e Style ID.
