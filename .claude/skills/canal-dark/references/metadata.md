# Metadata

Artefactos: `metadata.json`, `publish.txt`.

Campos úteis: title, description, tags, platform, visibility, `productionId`, `contentId`, `version`, `packageStatus`, provider trail.

YouTube real: `POST /api/validation/dry-run-report` **antes** de qualquer upload. Kill switches do CWM permanecem.

## Monetização (obrigatório)

Nunca dizer: “este vídeo será monetizado”.

Usar:

> O pacote foi preparado para publicação; elegibilidade para monetização depende das políticas da plataforma, direitos, originalidade, histórico do canal e outros fatores.

TikTok / Instagram / Pinterest publishing: `NOT_CONFIGURED` no CWM actual (Fase 5 = YouTube controlado).
