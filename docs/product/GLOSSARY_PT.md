# Glossary PT — linguagem pública (BP5)

Termos **proibidos na UI do comprador** (usar PT). Nomes técnicos de API/código podem permanecer internos.

| Evitar na UI | Usar |
|--------------|------|
| Wishlist | Lista de desejos |
| Top Movers | Em alta / Em tendência |
| Escrow | Compra protegida |
| Marketplace | Loja (ou omitir) |
| Listing | Anúncio |
| Near Mint / NM | Quase nova (NM) |
| Lightly Played / LP | Pouco usada (LP) |
| Moderately Played / MP | Usada (MP) |
| Heavily Played / HP | Muito usada (HP) |
| Damaged / DM | Danificada (DM) |
| Foil | Acabamento especial (foil) |
| Deck Builder | Montar baralho |
| Runtime / Identity / Financial / Analytics | (ocultar do comprador) |
| Checkout | Pagamento |
| Cart | Carrinho |
| Trust Score | Nota da loja |

Siglas de condição: sempre com rótulo por extenso ao lado ou no `title`/texto visível.
