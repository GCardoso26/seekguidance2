# AI Content Machine

**Marca:** NEXUS IA  
**Preço:** R$397 (faixa R$297–R$497)  
**Posição no funil:** upsell após Starter Kit

## Promessa

Sistema completo para pesquisar, gerar, distribuir e monetizar conteúdo curto com IA — sem prospecção fria.

## Módulos

1. **Sistema de pesquisa** — tendências, comentários, concorrentes, keywords  
2. **Banco de ideias** — template + taxonomia A/B/C  
3. **Prompts avançados** — pesquisa, roteiro, derivação, oferta  
4. **Geração de roteiro** — biblioteca + padrões de hook  
5. **Produção de vídeos** — stack dark (voz, legenda, B-roll)  
6. **Automações n8n** — fluxos prontos (JSON)  
7. **Calendário** — 30/60 dias multiplataforma  
8. **Templates** — landing, obrigado, e-mail, WhatsApp, bio  
9. **Análise** — painel views → cliques → leads → vendas  
10. **Monetização** — front R$67, upsell, afiliados
