# Visual Direction

## Objetivo

Produzir imagens que pareçam parte do mesmo produto audiovisual,
e não imagens independentes geradas por IA.

## Hierarquia

1. Visual Bible
2. Character/Location/Prop identity
3. Scene intent
4. Composition
5. Camera
6. Lighting
7. Style
8. Generation parameters

## Proibido

- estética horror não solicitada;
- iluminação excessivamente escura;
- olhos deformados;
- mãos deformadas;
- anatomia impossível;
- excesso de contraste;
- glitch;
- VHS;
- gore;
- surrealismo não solicitado;
- texto aleatório;
- watermark;
- estética "AI slop";
- aparência de deep web;
- stock-photo genérico quando houver alternativa.

## Cada cena deve responder

WHAT:
O que estamos mostrando?

WHY:
Por que esta imagem existe neste momento do roteiro?

WHO:
Quem aparece?

WHERE:
Onde?

WHEN:
Quando?

CAMERA:
Como a câmera observa?

LIGHT:
Como é iluminada?

STYLE:
Qual estética?

CONTINUITY:
Quais elementos precisam permanecer iguais?
