# Business Program 5.1 — Product Perception Excellence

**Mode:** Perception only · **No new features / modules / platforms / pages**  
**After:** BP5 Sprint 1 (friction removals)

## Rule

Every change must answer: **Does this make the user trust more?**  
If not a clear yes → do not ship.

When two solutions are correct → pick the one that needs **less thought**.

## Scores

- **PPS** (Product Perception Score): weighted 0–100 · gate **≥ 95**
- **PAS** (Product Aura Score): Aura · Memorability · Elegance · Spend courage · Clarity · gate narrative in scorecard
