## 1. Consenso absoluto (8/8)

| Problema | Como perceberam |
|----------|-----------------|
| Não dá pra comprar com confiança | Lojas “teste/debug”, produtos seed, sem foto |
| Busca falha no que o cliente quer | Lightning Bolt 0, Charizard 0, ETB 0, playmat 0, deck box 0 |
| Identidade confusa (loja vs planos vs juiz) | Menu Planos; rodapé de torneio |
| Sem prova social | Zero avaliações / selo de loja |
| Vitrine parece laboratório | “Sleeve teste”, “ONEPIECE Carta #1”, “Loja de Testes 1” |

## 2. Maioria (≥75% = ≥6 personas)

- Home “Carregando a loja…” / demora percebida  
- Acessórios inexistentes ou lixo  
- Página de produto fraca / sem fotos boas  
- Termos / links do rodapé quebrados ou inúteis  
- Não chegam ao checkout com item desejado  
- Preços absurdos ou suspeitos (R$99,90 booster sem foto; R$15.000 sem foto)
